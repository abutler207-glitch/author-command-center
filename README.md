Author Command Center v10 — Mobile Sizing Fix

What's fixed:
- Prevents the whole page from becoming wider than the phone screen.
- Keeps wide tables scrollable inside their cards instead of pushing the entire app sideways.
- Makes metric/trend cards match the top layout width more cleanly on mobile.
- Header toolbar is cleaner on small screens.

Deploy:
1. Upload/overwrite all files in your GitHub repository with this folder's contents.
2. Commit changes.
3. Open your GitHub Pages URL with ?v=10:
   https://YOURUSERNAME.github.io/author-command-center/?v=10

If your phone still shows the old layout:
- Delete the old Home Screen icon.
- Open the ?v=10 URL.
- Add the ?v=10 page to Home Screen again.

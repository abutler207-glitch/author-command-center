Author Command Center v28 — Tab Rename

Deploy:
1. Upload/overwrite all files in your GitHub repository with this folder's contents.
2. Commit changes.
3. Open your GitHub Pages URL with ?v=28:
   https://YOURUSERNAME.github.io/author-command-center/?v=28

If your phone still shows the old tab names:
- Delete the old Home Screen icon.
- Open the ?v=28 URL.
- Add the ?v=28 page to Home Screen again.

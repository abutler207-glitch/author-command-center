Author Command Center v12 — Sticky Home Button

What's changed:
- Replaced the top Export JSON button with a Home button.
- Home returns you to the Dashboard and scrolls to the top.
- Export JSON is still available through the Backup/Drive Backup workflow.
- Header shows v12 after deployment.

Deploy:
1. Upload/overwrite all files in your GitHub repository with this folder's contents.
2. Commit changes.
3. Open your GitHub Pages URL with ?v=12:
   https://YOURUSERNAME.github.io/author-command-center/?v=12

If your phone still shows the old layout:
- Delete the old Home Screen icon.
- Open the ?v=12 URL.
- Add the ?v=12 page to Home Screen again.
